There are 3 main paths at the moment for contributing:

## Follow along

Sign up above and you'll hear when there's something to try. If you know someone who runs software for a city, a school or any other organization, send them [the plan](/plan).

## Join the discussion

For now, discussions will be on [GitHub](https://github.com/orgs/27stack/discussions), but don't be afraid to join if you're not a developer! GitHub Discussions are like a normal forum, you don't need to know how to code to use them.
